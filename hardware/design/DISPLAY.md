# CL40BC264-40C 非触摸屏

用户指定 CL40BC264-40C 的 Without RTP 版本，替代此前所有候选。此前误传的 CL24CK229-18A 不采用。PCB 暂保留 88 × 125 mm。

资料：用户提供的 `CL40BC264-40C_RTP&WithoutTP.rar` 中 `CL40BC264-40C_SPEC_V0 鸿讯电子.pdf`（第 3–9 页）及 `CL40BC264-40C接线图.pdf`。已核对非触摸机械图与 8 位并口接线图；厂商原始文件和示例代码未复制入开源仓库。

## 已确认参数

| 参数 | 数值 |
| --- | --- |
| 对角线 / 分辨率 | 4.0 英寸 / 320 × 480 |
| 驱动 IC | ILI9488 |
| 显示区 | 55.68 × 83.52 mm |
| 模组外形 | 60.88 × 94.57 mm |
| 非触摸版厚度 | 2.48 ± 0.15 mm，不含双面胶 |
| 排线 | 40 pin，0.5 mm 间距；端部宽 20.50 mm |
| 插入端厚度 | 0.30 ± 0.05 mm（FPC + PI） |
| 视角方向 | 12 点钟方向；不将其标为 IPS |
| 接口选择 | 8080 8 位并口，IM0=1、IM1=1、IM2=0 |
| VCC / IOVCC | 接线图采用 3.3 V；规格表正常工作上限 3.3 V，最终电源需计入容差 |
| 背光 | 8 颗白光 LED 并联；正向压降 2.9 / 3.1 / 3.3 V（最小/典型/最大） |

厚度不能用规格书第 3 页带 RTP 的 3.62 mm。现有 PCB 文档层 61 × 95 mm 占位可作近似包络，但未包含 FPC 折弯、连接器、装配公差和禁布区，不是最终机械封装。

## 40 pin 接口分配

| 屏幕针脚 | 屏幕信号 | 计划连接 |
| --- | --- | --- |
| 1–4 | XL / YU / XR / YD | 非触摸版本不连接 |
| 5、16、37 | GND | GND |
| 6 | IOVCC | 显示 I/O 电源，拟 3.3 V |
| 7 | VCC | 显示电源，拟 3.3 V |
| 8 | FMARK / TE | 本版暂不接，保留调试焊盘方向 |
| 9 | CS | LCD_CS_N / GPIO10 |
| 10 | RS | LCD_DC / GPIO9 |
| 11 | WR | LCD_WR_N / GPIO8 |
| 12 | RD | 写入模式固定为高电平（IOVCC），不能悬空 |
| 13 | SPI_SDA | 按厂商并口图接 GND |
| 14 | SPI_SDO | 不连接 |
| 15 | RESET | LCD_RESET_N，GPIO 扩展器控制；上电默认状态待落实 |
| 17–20 | DB0–DB3 | LCD_D0–D3 / GPIO4、5、6、7 |
| 21–24 | DB4–DB7 | LCD_D4–D7 / GPIO15、16、17、18 |
| 25–32 | DB8–DB15 | 按厂商 8 位并口图接 GND |
| 33 | LEDA | 背光驱动输出，禁止直接接 MCU GPIO |
| 34–36 | LEDK | 三脚接同一背光阴极网络，经限流/驱动回路 |
| 38、39 | IM0、IM1 | IOVCC |
| 40 | IM2 | GND |

GPIO21 保持 LCD_BL_PWM，用于控制背光驱动。上述是连接设计依据，尚未在 CAD 中完成显示连接器、供电、复位、背光和封装；不能当作制造网表。

## 背光和装配待办

- 第 5 页背光电流表的 160 / 200 mA 应结合原页列位置及供应商确认典型/最大值；暂按 200 mA 预留驱动和热预算，不据此承诺续航。
- 接线图用 3.3 V + 2.2 Ω 限流作示例。这不是恒流方案，不能据此保证电流；需按电源容差、LED 压降和实测选择 PWM 背光电路。
- 40 pin / 0.5 mm / 0.3 mm 只是连接器筛选条件。必须核对接触面、锁扣方向、焊盘编号和最终折弯方向，再确定采购型号与 PCB 封装。
