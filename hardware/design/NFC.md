# NFC 读写与卡片模拟

2026-09-26 用户确认：同时希望自定义 NFC 卡和兼容已有卡，目前不知道已有卡的类型。Rev A 保留 PN7160A1HN 的读写及卡模拟能力，兼容范围按协议核实，不把“可读到”视作“可模拟”。

## 已确定的能力边界

- 自定义卡模拟以 NFC Forum Type 4 / ISO-DEP 为目标，可承载 NDEF 文字、链接及应用数据。
- PN7160 的 NFC-A/B 卡模拟仅支持 ISO-DEP；MIFARE Classic 读卡能力不代表 Classic 卡模拟能力。已有门禁卡的类型、应用协议和认证方式未确认，不能保证兼容。
- 不增加 125 kHz 低频 ID 卡电路；这属于另一套射频硬件。
- 首版按设备开机时模拟设计。主控处理动态 APDU；后续也可评估芯片内部 NDEF 模拟。软关机时 VEN 拉低，不承诺关机、没电或电池断开时刷卡。

依据：[NXP AN13861，卡片模拟](https://www.nxp.com/docs/en/application-note/AN13861.pdf)，第 5、6 节。其主机处理与控制器内 NDEF 模拟是两种软件路径，不能当成任意卡类型转换。

## 硬件约束

PN7160A1HN/C100Y 为 I²C 版本；与 TCA9535 共用 GPIO44/2，IRQ 接 GPIO47，VEN 由扩展器控制并下拉，复位后默认关闭。GPIO47 不是本板选用的 RTC 唤醒入口，因此不要默认承诺主控深睡时动态卡模拟。

NFC 核心、逻辑和 RF 输入都接常供电 3V18，以免共享 I²C 上拉在外设关闭后反向供电，并为2.7V的TXLDO提供稳定输入。CFG2配置及电流额度见 [电源设计](POWER.md)。芯片内部1.8V输出仅连其相应电源脚和去耦，不能接外部3V18。

NFC图页已画入主芯片、九个去耦电容及27.12MHz的XRCGB27M120F3M10R0晶体。两只16pF负载电容为调试初值，最终按RF频偏及启动测试修订。晶体2/4脚为NC，不能按普通接地外壳晶体接线。

天线须连同屏幕金属背板、电池、铁氧体及外壳验证。用户接受板长增加至135mm，优先预留右下角34×24mm板载线圈；屏幕下边缘y=38.5mm，线圈上边缘y=25mm，电池也避开。外接柔性天线不作为本轮默认方案。匹配值必须来自实际天线阻抗和最终装配，参考板参数只能作调试起点。

对称匹配需启用并校准 DPC；卡模拟还需验证不同读卡器、距离和偏移下的负载调制。参考：[NXP AN13892](https://www.nxp.com/docs/en/application-note/AN13892.pdf)、[AN13219 天线设计](https://www.nxp.com/docs/en/application-note/AN13219.pdf)。

## 样板验收

1. I²C/NCI 初始化、VEN 复位、IRQ 和芯片固件版本读取。
2. 用已知类型标签验证读取与可写区写回，确认错误恢复。
3. 手机和读卡器读取设备模拟的 Type 4 NDEF，验证反复靠近/离开及模式切换。
4. 确认已有卡类型后另列兼容性用例；不以 NFC UID 相同作为应用层兼容证明。
5. 最终装配下测匹配、RF 电流、读距及卡模拟稳定性；结果实测前不填合格或保证距离。

当前 NFC 主芯片和RF匹配电路已画入工程；PCB线圈、布局布线和实机验证仍未完成。RF_Service图页增加160nH/750pF EMC滤波、62pF串联/200pF并联匹配、每侧两只1Ω/0.25W串联、合计2Ω阻尼和可选接收取样点。默认2.2kΩ从EMC取样；替换为天线取样时拆掉该对电阻，再装6.8kΩ，不能两组同时装。所有射频值都是待实测的调试初值。

计算依据、假设与复现脚本见`../review/nfc-matching-estimate.json`和`../tools/nfc_matching_estimate.py`。34×24mm四匝线圈的近似电感约1.03µH，不是电磁仿真或实测值。按AN13219选择对称调谐初始目标11Ω（TVDD≤3.3V），必须启用并校准DPC。

阻尼料号为1206W4F100KT5E / C17928（原生库标记Basic Part，国内订单仍待核价）。复核模型每只约0.112W，须按温度降额及实测确认。NFC连续载波和PRBS测试模式不运行DPC，调试时必须单独监控电流和限制驱动，不能假定生产模式的DPC仍在保护。
