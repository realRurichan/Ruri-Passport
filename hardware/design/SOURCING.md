# 选型与采购约束

2026-09-26 用户要求：**全量使用基础库，非必要不用扩展库元件**。适用于整份硬件BOM与之后的每次改板。

1. 先查国内嘉立创SMT基础库，确认实际库类型与可用库存；国际JLCPCB分类不能代替国内分类。
2. 普通阻容、按键和通用半导体优先基础库，可调整封装、标准阻值或串并联组合；每次重算电气要求并修改PCB，不能为了沿用旧封装而保留扩展料。
3. 扩展料只作为逐项论证后的例外。论证必须记录功能/电气/机械要求、基础库替代查询及失败原因、替代电路的代价。未完成审核的扩展料不等于“必要”。
4. 保留用户要求的Wi-Fi/BLE、NFC读写与卡模拟、SD、扬声器、mic、IR收发及已指定屏幕。基础库优化不得静默删除功能。
5. 降本按两套全嘉立创贴片总价核算，含起订量、损耗、换料、封装/焊点、供料；不得只比较元件单价或假定基础库必然免掉所有加工费用。
6. 变更后同步原理图、PCB、BOM、坐标及报价；当前报价试算与CAD不一致时必须明确标记，不能直接下单。

全量57行基线分类及待办见 ../review/basic-library-audit-20260926.json。该审核尚未完成，当前不能声称已达成全量基础库优化。
