# 制造候选独立审核：一次性检查

审查者仅读取候选 EPRO2、Gerber ZIP、BOM/CPL；未调用 EDA 或修改工程。输入 SHA256 和独立计算见 checks.json；复现命令 `python3 hardware/review/final-fab-independent/check.py`。

## 直接检查结果

- NFC 线圈不是依据 DRC 零错误推定：直接从 EPRO2 PCB POLY e14 重建全部 16 条中心线，独立匹配 Top Gerber，16/16 段及 0.4 mm 线宽均一致。四匝串行矩形螺旋连续。
- 桥接铜 e3206 的真实范围为 x=84.5–84.9 mm、y=21.3–22.0 mm；与线圈只重叠第 16 条（最后一条）线段。至其它匝铜边最小间距 0.300 mm。ANT_B 的 Ø0.6 mm 过孔在 (84.7,22.0)，连接末端，未连接隔邻匝；该局部桥接未造成跨匝短路。ANT_A/ANT_B 两个网络名是线圈两端，直流连续本来就是线圈的物理行为。此检查不证明射频匹配或读卡距离。
- BOM 57 行、144 个安装位号，数量合计 144，无重复或空供应商编号。CPL 144 行，与 BOM 位号集合完全一致、料号一致。
- CPL Ref X/Ref Y 与 EPRO2 元件原点一致（<0.1 μm）；角度按 360° 等价检查、面别匹配。J1 的 Mid Y 60.625 与 Ref Y 59 是封装重心与原点的正常区别，不能据此移动元件。SW6 -90° 与 CPL 270° 等价。
- USB 两个 Ø0.65 mm 非金属定位孔在 x=41.11/46.89、y=6.28 mm。四个宽 0.6 mm 的金属槽在 x=39.68/48.32；其中两槽长 1.7 mm、另两槽长 1.4 mm（含半圆端）。槽与定位孔均在钻孔文件，未遗漏。
- NPTH 总计 7 孔（包含四个固定孔、USB 两孔、MIC 声孔）。四层铜文件存在；外形闭合 88×85 mm。

## 必须在完整贴片下单前解决/确认的事项

1. CPL 中 USB J2 标为 `SMD=No`，但仍已包含在 144 个坐标内。它有 SMT 信号脚及金属固定槽；嘉立创报价导入须确认 J2 被分配机贴/支持的焊接工艺，不能因筛选 SMD 误删而得到缺 USB 的全贴片包。具体是否需要额外工艺费由报价导入结果决定，现有 CSV 本身未漏位号。
2. 检查只验证库存文件的制造几何和坐标，不验证当前库存、可贴片料号/免换料费状态。因此不能据这份报告宣告两套全贴片可立即下单或确定报价。MIC1 两套供货此前存在疑问，需当前库存/报价证据。
3. 当前 Gerber 为 12:13:55 导出的 REVIEW 文件；本报告以其 SHA256 锁定，不能覆盖后续修改。正式发布包需从最终保存工程重导，并做一致性检查、记录新哈希。

## 样板验证项（不伪装为已完成）

NFC 匹配/天线性能、USB 实际信号质量、功耗/硬关机、充电温升及屏幕排线实装需样板验证。U7 热焊盘过孔吸锡和 USB 非金属孔周围铜间隙需制造商 DFM 接受；本次未建立完整焊膏吸锡模型或查得制造商对该订单的验收结论。

结论：本次局部独立复核未发现 NFC 跨匝短路或 BOM/CPL 错位；能够提交制造商做 DFM/贴片报价审核。要称为两套全贴片可下单版本，必须闭环 J2 焊接工艺、必需器件供货和最终导出版本一致性。未作购买或付款授权。
