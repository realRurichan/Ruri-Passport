# Optics 独立只读审查

2026-09-26，一次性审查。终止条件：列出有依据的问题、最小修复、结论即停止；未修改任何工程或操作原生 EDA。范围为 `hardware/tools/add_optics.py` 及给定电源/屏幕边界。根据任务禁止操作原生 UI，本轮**不是独立原生网表或 PCB 封装几何复核**，不宣称实际导出的连通性通过。

**结论：FIX FIRST — F1。换一个电容值后，可继续 PCB 设计；背光仍是需样板验证的模拟电路，不能宣称量产或瞬态验证完成。** 未发现厂家引脚接反、静态过流或已证明的 MOS SOA 超限。F2 为文字和使用范围修正，不要求换整套电路。

## 有依据的问题及最小修复

### F1 / SERIOUS（接收可靠性，非器件损坏）：IR 接收滤波电容低于厂家应用电路值

- 证据：C24=1uF、C25=0.1uF，仅 1.1uF 标称；Everlight IRM-H6XXT/TR2 Rev.3 第2页应用电路明确画出 **47–220Ω、≥2.2uF**，且要求贴近 VCC/GND。R50=47Ω正确，电容不满足参考值。
- 场景：本板同时有 Wi-Fi、电源转换与背光；不足的局部滤波增加受电源扰动误触发/丢码的风险。未实测误触发，不能声称一定发生。
- 最小修复：C24 改为 **4.7uF / 10V X5R**，选实际在约3.2V和温度范围内有效电容仍≥2.2uF的料；C25保留。该值已用于别处，可能不增加料种。R50、C24、C25紧贴接收器。

### F2 / MINOR：IR 36.4mA 上界引用了未保证的最低 Vf

- 证据：图中文字使用 Vf≥0.9V；IR91-21C/TR10 第3页只给 Vf 典型1.2V、最大1.5V，没有最低保证。两个200Ω、1%并联最小99Ω。
- 修正计算：用 Vf≥0、VDS≥0 的保守边界得 **4.5/99=45.45mA**；若实际 Vf=0.9V，则36.36mA只是条件计算。25°C下仍低于65mA绝对最大值。不能把65mA直接推广到+85°C：厂家第4页图在高温明显降额。
- 最小修复：改标注为“保守电流上界45.5mA；典型约30mA，需按温度降额”，并为整机声明工作温度范围。若要支持LED周围空气≥约50°C的长期连续高电平，需结合降额图增大R46/R47或强制有限占空比；目前没有这个高温使用要求，不能擅自判为电路失效。

## 已复核正确的部分

- 厂家引脚：TLV9001 **IDBVR** 为1OUT、2V−、3IN+、4IN−、5V+；不与DCK或TLV9001U混用。AO3400A标准SOT23为1G、2S、3D；其体二极管方向与低侧开关用途一致。IR91为1K、2A。IRM-H638为1/2GND、3OUT、4VCC。脚号在生成脚本中一致；实际库焊盘号需在原生网表/PCB审查继续验证。
- 背光标称全亮电流：3.18/21/1Ω=151.43mA。最坏1%分压比：3.223×1010/(19800+1010)=156.43mV；1Ω最低0.99Ω，加入±2mV失调及保守PSRR/CMRR增量后约 **160.5mA**。脚本163mA预算留有余量。IB仅给典型、器件温漂/布局未全部建模，因此这是工程静态预算，**不是所有瞬态绝对上界**。
- RC：20k并1k=952.38Ω，C=1uF，τ=0.952ms、fc≈167Hz。在20kHz、50%占空比且理想电容/驱动下，参考峰峰纹波约 **1.99mV**，约对应2mA峰峰电流纹波；±20%容量最低时约2.49mV。全亮100%没有PWM纹波。约5τ稳定，关灯也会有毫秒级渐灭。
- Q2正常最热角：以0.163A、VSYS4.5V、LED Vf2.9V计算，MOS耗散约 **0.235W**、VDS约1.439V，sense电阻约0.027W。AO3400A第4页DC SOA图上该点在曲线内。数据手册稳态θJA最大125°C/W是在1平方英寸、2oz测试板上，对应约29°C温升；**该温升不能直接当作本板实测值**。布局需留漏极散热铜，不能仅依赖SOT23标称1.4W（该标称采用≤10秒热条件）。
- IR接收器最小供电2.7V；47Ω在0.7mA静态电流下压降约33mV，3.18V正常供电有余量。47k输出上拉负载远低于2mA低电平测试条件。
- 低电池时LCD Vf接近VSYS，恒流会失去余量并变暗，电路没有升压能力；这是已知功能边界，不是3.18V掉压导致的推测。

## 未验证风险，不当作已发现故障

1. **启动、关断和欠压恢复**：TLV9001仅保证1.8–5.5V工作；供电低于1.8V时其输出不保证，100k门极下拉并不能证明供电爬升期间绝无闪光。掉压时运放可饱和，再接USB恢复VSYS可能产生瞬态。C28=1nF、R56=10k和1k门极串阻尚无环路仿真/测量。先把PWM置低再切外围电源是必要固件顺序，不能替代硬件测试。
2. **关断漏光**：运放正失调可能在PWM=0、外围仍供电时造成小电流；外围断电和门极下拉应关掉MOS，但没有实测。必要时后续增加硬件钳位或更换带可靠EN的恒流器件，当前证据不足以要求此修改。
3. **IR边沿与距离**：1k门极电阻配AO3400A，门极电容与Miller效应会占用38kHz载波的一部分时间；无法由6–7nC（另一测试条件）直接推出实际边沿。样板示波器确认8.8us/13.2us高脉冲实际LED电流，接收回放验证常用协议。厂家8米接收规格不是本板发射距离承诺。
4. **PCB布线**：R57使用Kelvin感测，模拟地回路避开RF/音频/开关电源电流；C26贴U9，C28与R56贴IN−。这些尚未在PCB上测量。

样板测试的最小集合：USB插拔/电池低压恢复/外围反复开关下测R57电流峰值；0/1/10/50/100%亮度测波形和振铃；封闭机身最热工况测Q2温度；Wi-Fi发射和扬声器工作时验证IR误码。第一套样板背光先用限流电源和低占空比，未确认峰值前不要直接满亮。以上均为待做测试，并非本审查已通过测试。
